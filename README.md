# Speciale Deals

Persoonlijke luxe- en sportdealsradar.

## Dashboard
Na inschakeling van GitHub Pages (Settings > Pages > Deploy from branch > main / root) staat het dashboard op https://dasphhs.github.io/specialedeals/.

## Werking
- `index.html`: dashboard met concrete, online gecontroleerde prijsindicaties, zoekfilters en uitbreidbare zoektermen.
- `deals.json`: lijst met geverifieerde voorbeelden, prijsreferenties en bronnen. Deze prijzen zijn een momentopname, geen liveprijzen.
- Zoektermen die je toevoegt worden lokaal in je browser opgeslagen, niet automatisch in GitHub. GitHub versiebeheer kan later worden verbonden aan een geautomatiseerde scanner.

**Belangrijk:** kortingen, voorraden, verzendkosten en ING-vouchers vóór afrekenen opnieuw controleren. Een product wordt pas als geverifieerde actuele deal aangemerkt na hercontrole.
